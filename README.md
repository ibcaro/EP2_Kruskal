# EP2_Kruskal

Escreva um programa em Linguagem C para o algoritmo de Kruskal ou Prim vistos
em aula. Seu algoritmo deve simular exatamente um dos algoritmos vistos em aula:
ou você vai inserindo as arestas de menor custo, tomando o cuidado de não formar
ciclos, ou você vai retirando as arestas de maior custo, tomando o cuidado de não
desconectar o grafo. É tarefa do grupo resolver problemas como representação do
grafo, verificação de ciclos ou de desconexão do grafo.
